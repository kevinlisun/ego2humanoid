# References

Shared bibliography for the Ego2Humanoid documentation. Documents cite entries in author–year form in square brackets
and link to the anchors below, e.g. `MoGe-2 [[Wang et al., 2025b](REFERENCES.md#wang2025moge2)]`. Add new entries in alphabetical order
of their key; BibTeX for each entry is available from the linked paper page.
